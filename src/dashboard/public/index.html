1. Architecture & Core Components

LocalXWeb is a complete, modern alternative to XAMPP designed for modern developers. It runs 100% self-contained without interfering with your system's global environment.

Apache HTTP Server (2.4.x)

High-performance HTTP web server pre-wired to execute PHP 8.x with custom DocumentRoot support.

MariaDB / MySQL (10.11 LTS)

Enterprise relational database engine with UTF-8 Unicode defaults, InnoDB storage, and password authentication.

PHP 8.x Engine

Pre-configured with essential extensions (mysqli, pdo_mysql, curl, mbstring, openssl, gd, zip).

phpMyAdmin Client

Browser-based visual database manager running on dedicated port 9999 with auto-synced credentials.

2. CLI Commands & Instant Project Runner

LocalXWeb features a rich terminal interface with built-in development server runner, project scaffolding, and system tools:

Instant Project Server Runner 
# Run current directory on default port 8080:
localxweb run

# Run a specific folder on a custom port (e.g. 3000, 8080, 8888):
localxweb run myapp --port 8888

# Run and automatically launch in default browser:
localxweb run myapp --port 8080 --browser
Project Scaffolding & Browser Launchers 
# List all web projects in DocumentRoot:
localxweb site list

# Scaffold new project (php, laravel, html):
localxweb site create blog --template php

# Open project in default browser:
localxweb site open blog

# Quick open LocalXWeb browser apps:
localxweb open          # Dashboard
localxweb open pma      # phpMyAdmin (port 9999)
localxweb open docs     # Documentation
Database Management from CLI 
# Create database with dedicated user and password:
localxweb db create shop_db --user shop_admin --password MySecret123!

# View saved credentials and reveal password in terminal:
localxweb db creds shop_db

# Set MySQL root password:
localxweb db root-password NewRootPass123!

# Export database SQL dump:
localxweb db export shop_db backup.sql
Diagnostics, File Explorer & Port Scan 
# Scan ports (80, 3306, 9999, 98) for conflicts:
localxweb ports

# Quick stack component integrity check:
localxweb check

# Inspect PHP binary, config path, and all 30+ extensions:
localxweb php-info

# Open DocumentRoot or config in Windows Explorer / OS Finder:
localxweb explore htdocs
localxweb explore config
Cache, Logs & System Maintenance 
# Deep clean everything (cache + logs + temp + pids):
localxweb clean all
# or shorthand:
localxweb clear all

# Clean temporary cache & OPcache only:
localxweb clean cache
localxweb clear cache

# Clean & truncate all service log files (free disk space):
localxweb clean logs
localxweb clear logs

# Reset stale process PID registry:
localxweb clean pids
Service Control & Clean Uninstall 
# Start or stop full stack:
localxweb start
localxweb stop

# Uninstall a specific service:
localxweb uninstall apache
localxweb uninstall mysql --purge

# Cleanly uninstall full LocalXWeb stack:
localxweb uninstall --purge

3. Database Connection & Credential Patterns

When you create a database with user & password, LocalXWeb permanently stores credentials in ~/.localxweb/credentials.json. You can inspect or copy snippets anytime.

Laravel & Modern Frameworks (.env) 
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=your_database_name
DB_USERNAME=your_database_user
DB_PASSWORD=your_database_password
PHP PDO Database Connection Script 
<?php
$host = '127.0.0.1';
$db   = 'your_database_name';
$user = 'your_database_user';
$pass = 'your_database_password';
$port = 3306;

$dsn = "mysql:host=$host;port=$port;dbname=$db;charset=utf8mb4";
$options = [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES   => false,
];

try {
     $pdo = new PDO($dsn, $user, $pass, $options);
     echo "Database connected successfully!";
} catch (\PDOException $e) {
     throw new \PDOException($e->getMessage(), (int)$e->getCode());
}

4. Configuration Files & Custom Settings

All configuration files are stored cleanly in your user profile under ~/.localxweb:

Global Stack Preferences ~/.localxweb/config.json
PHP 8.x Configuration ~/.localxweb/config/php.ini
MySQL / MariaDB Options ~/.localxweb/services/mysql/my.ini
Apache HTTPD Configuration ~/.localxweb/services/apache/conf/httpd.conf
Web Projects DocumentRoot ~/.localxweb/htdocs

5. Universal Multi-OS Architecture

LocalXWeb auto-detects your platform and uses native package managers or portable binaries:

Linux (Debian / Ubuntu)

Auto-installs via apt-get with systemd / direct daemon control.

Linux (Fedora / RHEL / Arch)

Supports dnf, pacman, zypper, and Alpine apk.

macOS (Apple Silicon & Intel)

Full native support via Homebrew (/opt/homebrew or /usr/local).

Windows (10 / 11)

Direct portable binaries with auto-detection of Microsoft Visual C++ Redistributable.

6. Troubleshooting & Port Conflicts

If a service fails to start, check the common resolutions below:

Port 80 busy (IIS or Skype) Go to Preferences > change Apache port to 8080 or stop IIS in Windows Services.
Port 3306 busy (Existing MySQL) Change MySQL port to 3307 in Preferences or stop the Windows MySQL service.
System Doctor Health Check Run localxweb doctor or open the System Doctor tab for instant port & extension diagnostics.
